How search works

Search looks through events, people, organisations, venues, suppliers, assets, trainees and training items{% if perms.RIGS.view_invoice %}, as well as invoices{% endif %}, and shows the best matches first.

  • Words are matched by their root, so lights finds lighting and rigged finds rigging. Accents are ignored, so cafe finds Café.
  • Every word has to match somewhere, but not necessarily next to each other.
  • Names are also matched loosely, so small typos and partial names (Portlnd, Portl) still find Portland.
  • A match in a name counts for more than a match in a description, which counts for more than one in the notes.
  • Events nearer to today are ranked above similar matches from years ago.
  • If a word doesn't appear anywhere, you might be offered a Did you mean suggestion.

Search syntax

"main stage"Words in quotes must appear together, in that order
marquee -cancelledA word starting with - must not appear
marquee or tentEither word can match

Searching by ID

  • Events: N01234 or 1234
    • {% if perms.RIGS.view_invoice %}
  • Invoices: #01234, or the event's N01234. A plain number matches both
    • {% endif %}
  • Assets: the exact asset ID or serial number
  • Training items: 1.2
  • Trainees: their initials
  • People, organisations, venues and suppliers: their ID number, or the start or end of their phone number

An exact ID match always comes first.
