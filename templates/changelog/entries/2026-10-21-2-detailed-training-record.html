The detailed training record has been redesigned so it's easier to see where someone is with each training item.

See what's changed
  • One heading per item: every training log for an item is grouped under it, newest first, instead of being spread across separate rows.
  • Every item is listed: items that haven't been started yet are shown greyed out, so gaps are easy to spot. Use Hide not started to hide them.
  • Progress at a glance: each item shows the furthest point reached, with a coloured bar using the same colours as before. Each log has a matching coloured dot.
  • Notes are tucked away: notes start collapsed. Open them one at a time, or all at once with Expand notes.
  • Links to the item list: item names on the detailed record and requirement items on level pages link to that item on the item list.
  • The old table is still there: use the Legacy view button if you prefer it.
