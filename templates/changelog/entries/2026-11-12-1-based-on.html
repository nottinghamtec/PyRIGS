The "Based on" field is now on the event form, so you can link a rig to the earlier event it repeats, or fix the link if it's wrong. Search by name, or type an event number such as N01234 to jump straight to it.

JoeGPT also looks for earlier editions when it reads an enquiry (the same client, a similar name, a similar time of year) and fills the field in for you on the Add Event button.
