Press {% shortcut_keys "K" %} on any page, or the shortcut badge in the search bar, to open the command picker.

  • Start typing to find a page or action, like Kanban, New Event or My Training Record, and press Enter to go there, or {% shortcut_keys "Enter" %} to open it in a new tab.
  • Type an event number such as N01234 to open that event directly, or pick Search for… to run a full search.
  • It only lists things you have access to, and the ones you use most recently appear first.
